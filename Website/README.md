# Eric Corbett — Portfolio website prototype

A three-page, responsive static website: `index.html` (Home), `teaching.html`, and `case-studies.html`. Publications in the header links to the supplied Google Scholar profile.

## Preview
Open `index.html` locally, or run `python3 -m http.server 8000` from this folder and visit http://localhost:8000.

## Deploy
Upload all HTML files, `style.css`, `script.js`, and the `assets/` folder to the same web directory. On an existing site, review existing navigation and filenames before replacing `index.html`.

## Design
Original composition inspired by the editorial storytelling of dylantao.github.io and Material Design 3 concepts (tonal surfaces, rounded components, semantic color, motion restraint). This is not a copy of either site's code or assets.
